## Проверенные сценарии

Вход с настоящей cookie NextAuth, отказ при неверном пароле, редирект защищённой страницы без сессии. Разные профили и группы двух студентов. Просмотр дня, недели и следующей недели, оценок и среднего балла. Выбор типа справки, отправка заявки, наличие после перезагрузки. Сохранение черновика при переходе Back. Изменение статуса сотрудником через интерфейс. Готовый документ с «ОБРАЗЕЦ», уведомление и сохранение прочитанности. Чужая заявка и документ дают 404; студент не получает staff-очередь и не меняет статус; чужой Origin даёт 403. Мобильное меню закрывается Escape, возвращает фокус, скрытая панель inert; горизонтального переполнения в проверенных сценариях нет.

Тесты сервиса дополнительно проверяют устаревшую роль/блокировку, строгую схему ввода, SQL-параметры, rollback, идемпотентный статус, конкурентные локальные записи, долговечность ограничений и seed без сброса пользовательских действий.

Вторая итерация: создание отдельного вымышленного аккаунта, вход созданным паролем, отсутствие чужих заявок, границы обоих семестров, праздники и рабочая суббота 20 февраля. В браузере пройдена отправка обращения преподавателю, сохранение после перезагрузки, 404 для второго студента и ответ сотрудника. Серверные проверки покрывают конкурентную регистрацию, 72-байтовую границу bcrypt, откат выдачи учебных записей, миграцию старого расписания и атомарность уведомлений переписки.

## Исправления в ходе работы

- Пустые соседние недели: сервер выдавал только текущую; расширен ограниченный диапазон данных.
- Неверные ссылки уведомлений: добавлен префикс /dashboard и миграция старых seed-ссылок.
- Средний балл: добавлены числовые итоговые оценки; учитываются только закрытые дисциплины.
- Тип документа: выбранная карточка теперь задаёт начальное значение формы через URL.
- Успешный POST больше не зависит от следующего refresh, поэтому его ошибка не провоцирует повторную отправку.
- Мобильное меню: невидимые ссылки исключены из Tab, фокус удерживается внутри открытого меню.
- Контраст: затемнены малоконтрастные подписи и увеличены размеры текста.
- SQLite TRANSACTION_ACTIVE: локальные транзакции сервиса и лимитера используют общую очередь.
- npm optional native binding: после обновления lockfile выявлено отсутствие платформенного Rolldown binding; lockfile пересобран без установленных node_modules, платформенные зависимости восстановлены.

## Ограничения и непроверенное

- В dev-зависимостях npm audit сообщает 16 moderate-связей, восходящих к minimatch/ESLint. Устанавливать предложенный audit downgrade до несовместимых старых ESLint/Next-config не стали. Эти инструменты не входят в production npm ci --omit=dev; runtime-аудит чистый.
- Dockerfile и Compose подготовлены. **UNKNOWN**: сборка контейнера не запускалась из-за отсутствующего Docker daemon. Node.js production standalone проверен E2E.
- **UNKNOWN**: Vercel/удалённый Turso, публичный домен, доступность из России без VPN и работа до 28 ноября. Аккаунты не подключены; пользователь запросил инструкции.
- Это вымышленные учебные данные, а не интеграция с учебной системой. Расписание покрывает два фиксированных семестра 2026/27; другой учебный год требует обновления календарного модуля.
- Нет настоящей электронной подписи, внешней отправки email/push и восстановления пароля. Регистрация вымышленного студента без почты реализована по уточнению пользователя.
- Скриншоты отражают вымышленные аккаунты. Видео не записывалось; сценарий подготовлен отдельно.
