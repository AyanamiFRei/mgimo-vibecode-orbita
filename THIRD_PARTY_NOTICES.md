# Открытые компоненты

Используются версии из package-lock.json. Лицензионные тексты библиотек находятся в соответствующих npm-пакетах; они сохраняются при установке и сборке контейнера. Список прямых зависимостей проверен по их package.json; метаданные фиксируются в `docs/dependency-licenses.json`.

- Next.js, React, React DOM, NextAuth, Zod, Lucide React, tsx: MIT или ISC в соответствии с метаданными пакета.
- bcryptjs: BSD-3-Clause.
- @libsql/client: MIT.
- Vitest, Playwright, ESLint, TypeScript, Prettier: разрешительные лицензии MIT / Apache-2.0 согласно метаданным.

Lucide SVG-иконки используются из открытого npm-пакета. Сторонние фотографии, графические материалы и загружаемые web-шрифты не используются. Шрифт — системный стек пользователя. Собственный знак «Орбиты» и CSS-композиция орбит созданы в этом проекте. Официальные знаки вузов не используются.

Навыки и агенты ECC/Vercel уже присутствовали в рабочей папке до создания приложения; их исходные уведомления и лицензии сохранены в `.tools`.

Для публикации дополнительно приложены MIT notices: `licenses/ecc-MIT.txt` (исходный Everything Claude Code, автор указан в исходном README) и `licenses/vercel-web-interface-guidelines-MIT.txt` (использованные правила Web Interface Guidelines). Метаданные ранее установленного пака и зафиксированные commit сохранены в `.tools/*/manifest.json`.
